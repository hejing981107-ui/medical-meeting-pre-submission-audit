# Medical Meeting Pre-Submission Audit

一套面向第三方医学会议执行公司的严格提交前审计 Skill，用于系统检查医学会议、学术活动的结算、验收及提交材料，尽可能在正式提交前发现可能导致退件、补件、验收延误或回款受阻的问题。

## 核心能力

本 Skill 不只检查单份材料，而是先建立项目事实基准，再对整套材料进行跨文件、跨人员、跨费用和跨时间验证。

主要审核范围包括：

- Project Baseline 项目事实基准
- 项目场次识别与材料归属
- 必交材料清单与特殊验收要求
- 全文件关键字段一致性
- 文件名、版本、旧版及跨项目残留
- 日程、签到、专家角色与履约证据
- 劳务、专家协议和 PPT 一致性
- 通知、邀请函和会议总结
- 现场照片、物料、设备及数量证据
- 签到人数与全景最大可见人数核验
- 结算金额、重复费用和重复票据
- 发票字段及购买方统一检查
- 酒店、餐饮、住宿人员与间夜
- 大交通、小交通及完整时间链
- 本地专家住宿和远郊特殊情形
- 药企名称、Logo、药品商品名及审批编号脱敏
- 全材料时空逻辑与证据冲突处理

## 设计原则

### 证据优先

操作人的说明可以帮助理解项目，但不能直接覆盖材料中的错误、冲突或证据缺失。任何例外都应具备适用于当前项目且可以留档的正式依据。

### 全量审核

审核不抽样，也不会因为已经发现若干问题而停止。所有文件、关键字段、人员、费用和适用证据链都需要完成检查。

### 跨文件验证

Skill 会把日程、签到、PPT、劳务、交通、住宿、发票、照片和结算材料连接起来，判断这些证据能否共同支持同一项执行事实。

### 独立全量复审

每次审核都被视为一次全新的审核。即使材料已经整改，也必须从头重新执行完整流程，不以前一轮的问题清单、PASS 结果或整改说明作为本轮前提。

## 适用场景

- 医学会议结算材料提交前
- 学术活动验收材料提交前
- 学协会或项目方审核前
- 客户退件后的重新审核
- 会议项目归档前
- 回款支持材料整理阶段

## 安装

将本仓库克隆或下载到 Codex Skills 目录：

```text
~/.codex/skills/medical-meeting-pre-submission-audit/
```

目录中应保留 `SKILL.md` 和 `agents/openai.yaml`。

## 使用方式

向 Codex 提供项目材料，并要求使用 `medical-meeting-pre-submission-audit` 进行审核。审核开始前，准备好：

1. 本项目或本场会议的必交材料清单；
2. 学协会或项目方特殊审核、验收要求；
3. 当前准备提交的完整材料包。

若无法提供特殊要求，Skill 会按默认标准继续审核，不会因此阻断流程。

## 审核边界

本 Skill 聚焦会议执行事实、材料一致性、费用证据和提交质量，不审核药企内部立项原因、商业策略或产品策略，也不替代法律、税务、医学或最终验收机构的专业判断。

本 Skill 不承诺“100%合规”“保证验收通过”或“保证回款”。其目标是在当前提供的完整材料、已确认规则及审核范围内，尽可能发现剩余的可识别问题。
